# Lesson 4 · Chart every participant

About 90 minutes. [Open the walkthrough](walkthrough.md)

1. Include each participant tab in the workbook settings.
2. Add two comparison charts with one line per tab: steps and screen minutes.
3. Use the legends to compare participants on a shared date.

**Done when** the page has four charts and both new legends contain every configured participant’s sheet name.
