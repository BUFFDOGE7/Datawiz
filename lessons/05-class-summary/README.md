# Lesson 5 · Calculate class totals and averages

About 90 minutes. [Open the walkthrough](walkthrough.md)

1. Group the configured participants’ numeric step counts by date.
2. Add a daily total chart and a daily mean chart beneath the participant comparisons.
3. Check one day by dividing its total by the number of participants who reported steps. Include recorded zeros.

**Done when** the page shows six charts and both class summaries match the readings for your chosen date. Days without numeric readings have a gap.

**Bonus points:** Add the daily median, the daily mode, or both. Each exercise has an expandable solution in the walkthrough.
